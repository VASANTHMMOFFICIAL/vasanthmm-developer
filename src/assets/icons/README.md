# Icons

All icons in this project come from `react-icons` (Fa, Fi, Si, Tb, Md, Vsc
sets) — see the imports at the top of `src/data/skills.js`,
`src/data/services.js`, and the individual component files.

This folder is here in case you want to add custom SVG icons of your own
later (e.g. a personal logo mark).
